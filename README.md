## الأوضاع (4.4)
في أعلى كل صفحة مبدّل: عادي / أطفال. وضع المدرسة مخفي كلياً في هذا الإصدار (انظر آخر الملف لإرجاعه). كل وضع يغيّر الموقع كله (التصميم، النص، القائمة، الأنشطة). الوضع يُحفظ في المتصفح.
- عادي: الموقع كما هو (نبذة، قراءة، ألعاب، مكتبة).
- أطفال: ألوان بنفسجي/أصفر/وردي، نجوم تطفو، شخصية نجمة، شرح لكل عالم بلغة الأطفال (مقدمة + ثلاثة فصول في القارئ)، نجوم وملصقات. صفحات: activities.html، stickers.html.
- مدرسة: برتقالي + أخضر مخضرّ، لوح ودفتر. درس لكل عالم فيه أنشطة المعلّم مع الطالب (أسئلة شفهية، مقابلة تمثيلية، فكّر–زاوج–شارك، مشروع صغير) وتمارين فردية وورقة عمل، وكل شيء يُحفظ لكل عالم على حدة. صفحات: lessons.html، teacher.html، record.html.
- modes.html: صفحة اختيار الوضع. kids.html و school.html صارتا تحويلاً إلى الصفحتين الجديدتين.

## الملفات

- js/school.js: TCH = مقابلة ومشروع لكل عالم، REC = سجلّ الطالب، وصفحات المدرسة.
- css/style.css: التصميم الأساسي. css/modes.css: تصميم الأطفال والمدرسة والمبدّل.
- img/real: صور حقيقية (انظر README.txt هناك).

- يعمل بـ Firebase (Authentication: بريد/كلمة مرور + Google، وCloud Firestore). كل القيم (النقاط، العملات، سعر الصورة، مكافأة الإنجاز) في أول js/rewards.js ضمن REW. إن غيّرت REW.PRICE غيّر price() في firestore.rules أيضاً.

- الصفحات: account.html (لوحة المتصدرين، الإنجازات، المتجر). الاشتراك يتم من المتصفح فقط، فالحماية بالقواعد تحدّ من الغش ولا تمنعه تماماً (يلزم Cloud Functions لذلك).
